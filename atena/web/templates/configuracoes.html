Como obter e proteger a chave (resumo)
  1. Acesse platform.openai.com, crie uma conta e, em Billing, adicione crédito (pré-pago) e um limite de gastos.
  2. Em API keys, clique em Create new secret key, dê um nome (ex.: “ATENA”) e copie a chave (começa com sk-). Ela só é mostrada uma vez.
  3. Cole a chave acima e clique em Guardar chave. No Windows ela é protegida pelo DPAPI (vinculada à sua conta de usuário) e nunca vai para o banco de dados nem para backups.
  4. Clique em Testar conexão. O teste apenas lista os modelos disponíveis e não envia dados da pesquisa.
  5. Acompanhe os custos em platform.openai.com/usage e no painel de IA do projeto (estimativa local). Revogue a chave na OpenAI se o computador for compartilhado ou perdido.
